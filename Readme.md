Personal Wordlist Generator

A Python-based wordlist generator designed for **authorized cybersecurity labs, CTFs, and password-security testing**.

The program takes user-provided information such as name, date of birth, nickname, additional digits, and special characters, then generates combinations and saves them to a text file.


**For authorized security testing only.**
> Do not use this tool to guess or attack passwords/accounts that you do not own or have explicit permission to test.
